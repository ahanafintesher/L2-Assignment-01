# TypeScript Assignment 01

## Assignment Overview

This repository contains my solutions for **Assignment 01: Problem Solving with TypeScript & OOP**.

The assignment focuses on practicing TypeScript fundamentals, including functions, optional parameters, union types, type narrowing, readonly tuples, generics, interfaces, and Object-Oriented Programming (OOP).

It also includes two technical blog posts covering important TypeScript concepts.

## Technologies Used

- TypeScript
- Node.js
- JavaScript
- Object-Oriented Programming (OOP)

## Solutions Overview

The assignment includes eight problems:

1. **Optional Parameters:** Implementing a function with an optional multiplier.
2. **Union Types:** Processing string, number, and boolean values.
3. **Readonly Tuples:** Formatting location coordinates.
4. **Generics:** Combining multiple arrays using a generic function.
5. **Interfaces:** Filtering popular published courses.
6. **Generic Constraints:** Extracting object property values using `keyof`.
7. **OOP and Inheritance:** Implementing Employee and Manager classes with access modifiers.
8. **Async/Await and Promises:** Validating age using an asynchronous function.
